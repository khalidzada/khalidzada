## 🚀 Featured Project — SocialConnect

### Social Network + E-Commerce Platform

**SocialConnect** is a long-term engineering project demonstrating the design and development of a modern, modular web application using **ASP.NET Core, .NET 8, Entity Framework Core, SQL Server, Identity, Razor, REST APIs, and Bootstrap**.

The project covers considerably more than a simple CRUD application. It involves designing application architecture, domain boundaries, data access, APIs, reusable UI components, media handling, event-driven workflows, notifications, testing, and technical documentation.

* ASP.NET Core MVC / .NET 8

* SQL Server

* REST API design

* Repository & Unit of Work patterns
* Domain and application services
* Event-driven architecture
* Transactional Outbox concepts
* Notification architecture
* Media upload and finalization workflows
* Reusable ViewComponents
* Server-first UI architecture
* JavaScript module architecture
